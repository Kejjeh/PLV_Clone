# Pre-registration: xfp_bx v0 — box-score-era next-season FP-rate model

- **Date:** 2026-07-10
- **Status at write time:** panels built + spot-checked; NO model evaluation has been run yet.
- **Family:** `xfp_bx` — NEW model family (box-score era). This document declares the
  family's own gates; the rh3/rp3 +0.005 Δr gate does not apply because there is no
  existing production xfp_bx baseline (Rule 9 baseline here = the declared Marcel-lite).
- **Purpose of the family:** (a) era-robust validation on 40+ years instead of 2015+;
  (b) aging/career-arc priors on huge samples; (c) an ensemble opinion decorrelated
  from the Statcast stack; (d) substrate for future multi-horizon xFP.

## Data (frozen before evaluation)

- `data/research/boxscore_era/hitter_season_panel.csv` — 1960–2026, MLB Stats API
  season lines, mlbam + lahman(bbref) + retro keyed. 53,293 rows.
- `data/research/boxscore_era/pitcher_season_panel.csv` — 1970–2026, same source.
  31,970 rows.
- 2026 rows are in-progress and are EXCLUDED from all training/evaluation
  (used only for the current-player list in the step-4 output).
- 2020 (COVID 60-game) excluded as feature year T and as target year T+1
  (house convention, matches rh3/rp3 TRAIN_YEARS).
- Strike-shortened 1981/1994/1995 retained, subject to the volume filters below
  (documented; not special-cased).

## Task definition

**Hitters:** predict `fp_per_pa` in year T+1 from year-T box rates.
Pair filter: PA(T) ≥ 200 and PA(T+1) ≥ 200. Target years 1961–2025 for the
panel; the decade LOO uses target decades 1970s–2020s.

**Pitchers (SP leg):** predict `fp_per_start` in year T+1 from year-T box rates.
Pair filter: GS(T) ≥ 10 and GS(T+1) ≥ 10. Target decades 1970s–2020s.
(`fp_per_start` = season pitching FP / GS — an approximation for swingmen;
pure relief innings pollute it slightly. Documented, accepted for v0.)

## Baseline (declared before running)

**Marcel-lite:** weighted mean of FP-rate over years T, T−1, T−2 with weights
5/4/3, each year weighted additionally by its volume (PA or GS), regressed to
the *league mean of the target-decade-excluded training pool* with k = 200 PA
(hitters) / k = 20 GS (pitchers): `prior = (Σ w·vol·rate + k·μ) / (Σ w·vol + k)`.
Missing lookback years simply drop out of the sum. The league mean μ is computed
per-year from qualifying seasons (PA ≥ 200 / GS ≥ 10) to absorb era drift, using
the year-T value (no lookahead into T+1).

## Model (declared before running)

Ridge regression, house idiom (StandardScaler + RidgeCV, alphas = logspace(−1, 5, 80),
cv = 5 — same as `src/plv_clone/models/xfp/rh3.py::cross_year_eval`).

- Hitter features (year-T): `k_pct, bb_pct, iso, hr_per_pa, sb_per_pa, babip,
  r_per_pa, rbi_per_pa, fp_per_pa, marcel_prior, age, age², log(pa)`.
- Pitcher features (year-T): `k_pct, bb_pct, hr9, era, fip_box, ip_per_gs,
  fp_per_start, marcel_prior, age, age², log(gs)`.
- Era handling: all rate features AND the target are used raw (no z-scoring by
  year beyond the global StandardScaler); the marcel_prior carries the era level.
  If pooled-raw fails the gate, NO post-hoc era-normalized variant will be
  reported as the headline without a fresh prereg.

## Evaluation protocol

**LOO-by-DECADE:** 6 folds — hold out ALL pairs whose target year T+1 falls in
{1970s, 1980s, 1990s, 2000s, 2010s, 2020s}; train on the remaining decades
(plus the 1960s pairs, which are always-train history for hitters). Fit the
full pipeline on train, predict held decade. Marcel-lite needs no fitting and
is evaluated on the identical held-out rows.

Metric: Pearson r between predicted and actual T+1 rate, per held decade and
pooled over all held-out predictions.

## Gates (all three must pass)

1. **Pooled LOO-by-decade r (model) ≥ pooled r (Marcel-lite) + 0.01**, separately
   for the hitter model and the SP model (each gated on its own leg).
2. **Sign consistency:** model r > Marcel-lite r in ≥ 5 of 6 held decades.
3. **Statcast-era sanity:** the 2015–2025 slice of held-out predictions (from the
   2010s + 2020s folds) must show cross-year r that is BELOW rh3's known ≈0.62
   cross-year r (it cannot beat a richer feature set — if it does, suspect
   leakage) and within a plausible band (declared: pooled 2015–2025 r ≥ 0.35 for
   hitters, ≥ 0.30 for SP; below that the box model is too weak to be worth an
   ensemble seat). The gap vs 0.62 is reported as the **"Statcast premium."**

Note: the ≈0.62 rh3 anchor is a RoS-from-midseason correlation, not strictly
next-season; it is used as an upper sanity anchor only, not as an equivalence
target. Failing gate 3's lower bound = the model ships as research-stage panel
infrastructure only (aging curves still deliverable); it does NOT enter any
decision surface.

## What is NOT being claimed

- No integration into rh3/rp3/rprs2 (would each require their own
  `/validate-feature` run under Rule 9).
- Aging curves (step 3) are descriptive deliverables, not gated.
- The 2026 output file is an ensemble-research artifact, not a ranker.

### Panel build (step 1)

Source pivot documented: pybaseball's bundled Lahman is BROKEN (stale zip URL,
`BadZipFile`) and the baseballdatabank raw-CSV path 404s. The MLB Stats API
serves complete season lines for the full window (verified live: 1972
pitching, 1975 hitting) including `age`, HBP, TB, SB — so it is the single
source for both deep history and recent seasons. Crosswalk = Chadwick
register `key_bbref` (≡ Lahman playerID) + `key_retro`; coverage 99.8-100%
in every decade.

- `hitter_season_panel.csv`: 53,293 rows, 1960-2026.
- `pitcher_season_panel.csv`: 31,970 rows, 1970-2026 (RP FP columns NaN
  before holds exist ~2000; verified 1972 has no holds key, 2004 has 258
  pitchers with holds > 0).
- Spot-checks pass: Rickey 1982 FP 529 (0.81/PA, 130-SB year), Bonds 2001
  1.18 FP/PA, Trout 2013 0.77 FP/PA, Pedro 1999-2000 24.6-25.6 FP/start,
  Carlton 1972 23.3 FP/start, Rivera 2004 6.31 FP/g with 53 SV.

### The Statcast premium

Hitter 2015-2025 held-out r **0.569** vs rh3's ≈0.62 anchor →
**premium ≈ +0.05 r**. Caveat (declared in prereg): rh3's 0.62 is
RoS-from-midseason (has current-season info), bx is prior-season-only
full-year; the honest statement is "everything Statcast + in-season adds
over a pure prior-season box line is worth about +0.05 r on hitters."
SP slice r 0.575 — similar order.

### Aging curves (step 3, descriptive)

Delta method, volume-harmonic-mean weights, ages 20-40 (survivor bias
documented — uniform across eras, so era COMPARISON is valid):

- **Hitters (14,778 transitions): peak age 26 (ALL)**; per-era peaks
  27 / 26 / **31 (1990s — offense-explosion/PED anomaly, decline slope
  only −0.009/yr)** / 25 / 26 / 26. Decline slope (mean Δ fp_per_pa per
  year, ages 30-36) STEEPENS across regimes: −0.020 (1970s) → −0.025
  (2000s) → **−0.034 (2020s)**. The curve itself regime-shifts: aging is
  ~70% harsher today than in the 1970s-80s, i.e. modern career_stage
  priors should decay old hitters faster than history-pooled ones.
- **SP (6,086 transitions): fp_per_start is peak-on-arrival** — monotone
  decline from the earliest reliable ages (nominal "peak 20-21" in early
  eras is an n=28 anchor artifact; 2000s/2010s/2020s peak 25). Decline
  slope 30-36 is SHALLOWER now: −0.95 FP/start/yr (1970s) → −0.56/−0.64/
  −0.63 (2000s/2010s/2020s) — partly mechanical (IP/GS shrank, so there
  is less per-start FP to lose).
- Future Rule-9 candidate (NOT integrated): replace/inform rh3's
  `career_stage` and Marcel priors with these era-aware aging deltas.

### 2026 output + ensemble evidence (step 4)

`data/outputs/xfp_bx_season_2026.csv` — 477 rows (325 hitters, 152 SP),
mlbam + lahman keyed, 2026 xFP-rate + implied totals at reference volume.

Overlap correlations: **hitters corr(bx, rh3) = 0.741 (n=303); SP
corr(bx, rp3 data_driven) = 0.697 (n=113)** — correlated enough to be
sane, decorrelated enough (R² ≈ 0.49-0.55) that an ensemble seat is
plausibly valuable.

Biggest disagreements (z-score gap), with reads:

- BX ≫ rh3: Raleigh, Tucker, Wallner, Keaschall, Suárez, Marsee,
  A.Ramírez, Ozuna, Carter, Acuña — box history rewards monster 2025
  counting lines and veteran RBI/R accumulation the Statcast stack
  shades down (Suárez/Ozuna = classic old-slugger box-vs-process split).
- BX ≪ rh3: J.Walker, Mead, Dingler, Wood, N.Allen, Vargas, **Trout**,
  Schmitt, E.Díaz, Nimmo — thin/poor prior box lines where rh3 sees
  current-season process; Trout = age-33 + volume-thinned 2025 box line
  vs still-elite Statcast inputs.
- BX ≫ rp3: Mlodzinski (+3.05z — KNOWN v0 artifact: swingman relief
  innings inflate season-FP/GS), Lauer, J.Lopez, Webb, Manaea, Cantillo,
  SWR, Gallen, Junk, N.Martinez.
- BX ≪ rp3: Misiorowski, B.Miller, Cavalli, Schlittler, Buehler,
  G.Williams, Hancock, Mize, Meyer, Bradley — rookies/short box history
  where rp3's in-season stuff read dominates; exactly where the box
  model SHOULD defer.
